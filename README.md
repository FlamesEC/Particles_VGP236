# Hypotrochoid Draw Tool

This is a project that allows the visualization of hyptrochoids through circles with variable size, speed, and color.

Made in a total of 160 minutes for a Midterm in the VGP230 class.

![hypotrochoid gif](resources/image.gif)

## KEYBINDS:

* UP/DOWN: Radius of the Outer Circle

* LEFT/RIGHT: Radius of the Inner Circle

* W/S: Rotation Speed of the Outer Circle

* A/D: Rotation Speed of the Inner Circle

* 1: Shuffle Colors
